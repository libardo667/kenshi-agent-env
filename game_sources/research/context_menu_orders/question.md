# Which Kenshi orders apply to one exact target?

The controller needs the same target-specific order set a player receives from
a right-click without curating verbs in this repository and without opening or
overwriting a visible context menu.

The question is not whether an order is globally valid, whether Kenshi can show
success odds for it, or whether attempting it would produce a complaint. The
answer must preserve “the probe could not run” separately from “Kenshi offered
no order,” and dispatch must ask the same authority that published the offer.
